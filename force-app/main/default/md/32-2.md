## 処理説明

■本機能の前提条件

　・事務局ユーザー、支部ユーザー、支部連ユーザーを対象とする。税理士ユーザーは本機能を利用できない。
　・取込データが参照する 従事場所マスタ、会員、相談員マスタ、支部（事務所・法人）が登録されていること。

■本機能の処理対象

　・CSV ファイル（従事事業、従事事業明細、従事事業応募、従事事業応募明細、従事事業割当、従事事業実績）による一括登録。

## 処理詳細（概要）

**1. 初期表示**

・ログインユーザ情報を取得し、登録対象のチェックボックスをオフ、ファイル名を空で表示する。

**2. 画面アクション**

・登録対象ごとに CSV ファイルを選択し、登録ボタンで取り込む。

**3. 入力チェック**

・登録ボタン押下時に、ファイルの形式・各行の内容、および登録済みデータとの整合性をチェックする。エラーが 1 件でもあれば登録しない。

**4. データ登録・更新**

・事業（従事事業No.＋従事場所No.＋実施年度）ごとに 1 トランザクションで登録する。エラーの事業は登録せず、他の事業は登録する。
・詳細は「5.データ更新」「6.イベント処理詳細」を参照すること。

### No.2　チェックオン／オフ｜各ファイルのチェックボックス

```text
・チェックオンの場合
　　当該ファイルを登録対象とする。
・チェックオフの場合
　　当該ファイルを登録対象外とする（選択したファイルは保持する）。
```

### No.3　ボタン押下｜各参照ボタン押下

```text
ファイル選択ダイアログを表示する（同じファイルを選び直した場合も選択し直したものとする）。
・ファイルが選択された場合
　　当該行のファイル名に選択したファイル名を表示し、ファイルを保持する。
　　画面のエラー表示（画面頭部のメッセージ・エラー内容）を消去する。
・ファイルが選択されなかった場合
　　何もしない。
```

### No.4　ボタン押下｜登録ボタン押下

```text
画面のエラー表示を消去する。
入力チェックを行う（4.入力チェック No.1～3）。エラーの場合は画面頭部にエラーメッセージを表示し、何もしない。
確認ダイアログを表示する。「ファイルを取り込みます。よろしいですか？」（はい or いいえ）
・「はい」の場合
　　チェックありのファイルを読み込み、入力チェック（No.4～94）を行う。処理中は処理中の表示とする。
　　・チェックのエラーがある場合
　　　　画面頭部に「対象ファイルにエラーが見つかりました。」（SYSTEM-6105）を表示し、イベント「エラー内容表示」を呼び出す。全ファイルとも登録しない。
　　・チェックのエラーがない場合
　　　　事業単位で登録する（5.データ更新 (2)）。登録中は「登録中です（n / 全件数 件）」を表示する。
　　　　・すべての事業を登録できた場合
　　　　　　「登録しました。（従事事業 n 件）」（WLP029-0033）を表示し、画面を初期表示の状態に戻す。
　　　　・登録できなかった事業がある場合
　　　　　　画面頭部に「登録できなかった従事事業があります。（登録済み n 件、未登録 m 件）」（WLP029-0032）を表示し、
　　　　　　イベント「エラー内容表示」を呼び出す。選択したファイルはそのまま残す。
　　・想定外のエラーの場合
　　　　画面頭部にエラーメッセージを表示する。
・「いいえ」の場合
　　確認ダイアログを閉じ、何もしない。
```

```text
エラー内容のポップアップを表示する。
・表示内容：「エラーが n 件見つかりました。」、登録対象・ファイル名ごとのエラー件数
・チェックのエラーの場合：「ファイルの登録は行われていません。エラーログをダウンロードし、CSV ファイルを修正してから再度登録してください。」

```

## ■6.イベント処理詳細

### 6.1 コード変換

　画面のコード変換表で CSV のコードを選択リストの値に変換し、行ごとにサーバへ渡す。値は「40」7 章のとおり。【要確認 D-53・D-54】
　・変換表にないコード（支払調書区分の 0 等）、税理士区分 7・8（相談員の区分）は渡さない（空で登録）。
　・口座指定は true／false。

### 6.2 日付・時間の変換

　・日付：YYYYMMDD → 日付
　・時間：HHmm → 時間（秒 0）
　・実施時間帯明細（JSON）の時間：HHmm → HH:mm

### 6.3 明細の時間帯（実施時間帯明細）

　・取込データの明細の時間帯：CSV.実施時間帯（「HHmm-HHmm:人数」を「;」区切り）→ 省略時は CSV.開始時間～終了時間（人数＝募集人数）→ 省略時は 従事場所マスタの 開始時間～終了時間（人数＝募集人数）の順に求める。【要確認 D-55】
　・既存の明細の時間帯：実施時間帯明細（JSON）→ 空の場合は 開始時間～終了時間（人数＝募集人数）。
　・実施時間帯明細（JSON）の形：開始時間の順。応募画面（JUJ081）と同じ形。

```json
[{"startTime":"09:00","endTime":"12:00","count":1},{"startTime":"13:00","endTime":"17:00","count":1}]
```
