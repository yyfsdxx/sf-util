### No.1　初期表示｜画面初期化

```text
ログインユーザのユーザ種別（事務局ユーザ／支部ユーザ）および支部コードを取得し、保持する。【要確認 C-5】
各登録対象（従事事業、従事事業明細、従事事業応募、従事事業応募明細、従事事業割当、従事事業実績）のチェックボックスをオフ、ファイル名を「ファイルを選択してください」で表示する。
```

### No.2　チェックオン／オフ｜各ファイルのチェックボックス

```text
・チェックオンの場合
　　当該ファイルを登録対象とする。
・チェックオフの場合
　　当該ファイルを登録対象外とする（選択したファイルは保持する）。
```

### No.3　ボタン押下｜各参照ボタン押下

```text
ファイル選択ダイアログを表示する。
・ファイルが選択された場合
　　当該行のファイル名に選択したファイル名を表示し、ファイルを保持する。
・ファイルが選択されなかった場合
　　何もしない。
```

### No.4　ボタン押下｜登録ボタン押下

```text
入力チェックを行う（4.入力チェック No.1・2 参照）。エラーの場合はエラーメッセージを表示し、何もしない。
確認ダイアログを表示する。「ファイルを取り込みます。よろしいですか？」（はい or いいえ）
・「はい」の場合
　　① チェックありのファイルを読み込み、入力チェックを行う（4.入力チェック の実装方式が LWC のもの）。
　　　　エラーがある場合は、イベント「エラー一覧表示」を呼び出し、処理を終了する（一時取込に登録しない）。
　　② 処理中の表示（スピナーと「処理中です。しばらくお待ちください。」）にし、画面の操作を不可にする。
　　③ 取込管理・一時取込を登録する（5.データ更新 (1) 参照）。
　　　　エラーの場合は、システムエラーのメッセージを表示し、処理中の表示を解除して処理を終了する。
　　④ チェック Batch を開始する（5.データ更新 (2) 参照。チェック後の登録・補償は Batch 内で続けて行う）。
　　⑤ 一定間隔（5 秒）で取込管理のステータスを取得し（5.データ更新 (5) 参照）、終了のステータス（チェックエラー・登録完了・補償完了・補償エラー）になるまで待つ。
　　⑥ 処理中の表示を解除し、ステータスにより以下を行う。
　　　　・登録完了　　：「登録しました。」を表示し、チェックボックス・ファイル名を初期表示の状態に戻す。
　　　　・チェックエラー：一時取込のエラーを取得し（5.データ更新 (5) 参照）、イベント「エラー一覧表示」を呼び出す。全ファイルとも登録しない。
　　　　　　　　　　　取込管理.異常内容 がある場合（チェック Batch のシステムエラー）は、システムエラーのメッセージを表示する。
　　　　・補償完了　　：「登録中にエラーが発生したため、登録を取り消しました。」を表示する。（メッセージ ID 未定【要確認 C-8】）
　　　　・補償エラー　：「登録の取消中にエラーが発生しました。システム管理者に連絡してください。」を表示する。（メッセージ ID 未定【要確認 C-8】）
・「いいえ」の場合
　　何もしない。
※ ⑤の途中で画面を閉じた場合も Batch は最後まで実行する。後から結果を確認する方法は【要確認 E-5】。
```

### No.5　ボタン押下｜クリアボタン押下

```text
画面を初期表示の状態に戻す（チェックボックス、選択したファイル、エラー一覧を消去する）。
※DBは更新しない。処理中（No.4 ②～⑥）は押下できない。
```

### No.6　ボタン押下｜戻るボタン押下

```text
遷移元の画面（従事事業メニュー）に戻る。
※DBは更新しない。処理中（No.4 ②～⑥）は押下できない。
```

### No.7　呼出し｜エラー一覧表示呼び出し

```text
エラーを一覧で画面に表示する。表示項目は「ファイル名」「行番号」「メッセージ」とし、登録対象の並び順（従事事業～従事事業実績）、行番号の昇順で表示する。
1 行に複数のエラーがある場合は、エラーごとに 1 行で表示する。
```

### (3) 登録 Batch（(2)⑥）

　従事事業 → 従事事業明細 → 従事事業応募 → 従事事業応募明細 → 従事事業割当 → 従事事業実績 → 従事フラグ更新 の順に、チェックありの登録対象ごとに実行する。取込管理.処理中の登録対象 に実行中の登録対象を設定する。

① 処理単位（execute）の開始時に取込管理.ステータスを取得し、「登録中」以外の場合は何もしない（前の処理単位でエラーとなった場合に、以降の登録を行わないため）。
② 一時取込の各レコードから正式レコードを作成し、登録する。設定値は「②-1～②-6」を参照する（記載のない項目は設定しない。「CSV.〇〇」は一時取込に保持した CSV の値。コード変換は 6.1、日付・時間の変換は 6.2 参照）。
　親レコードの ID は、既存の親の場合は一時取込の参照解決項目（従事事業ID 等）、取込データの親の場合は親一時取込.登録ID を設定する。
③ 登録した ID を一時取込.登録ID に設定し、一時取込を更新する。②と③は同じトランザクションで行う（登録した ID の記録漏れを防ぐため）。
④ ②・③でエラー（入力規則・DML の例外等）が発生した場合は、当該処理単位の登録を取り消し、取込管理.ステータス＝登録エラー、異常内容＝エラーの内容 に更新する。
⑤ 例外として捕捉できないエラー（ガバナ制限超過等）の場合は、finish で当該 Batch のジョブのエラー件数を確認し、1 件以上の場合は 取込管理.ステータス＝登録エラー に更新する（6.4 参照）。
⑥ 各登録対象の終了後（finish）、取込管理.ステータスにより以下を行う。
　・登録中：次の登録対象の登録 Batch を開始する。最後（従事フラグ更新）の場合は、ステータス＝登録完了、処理終了日時＝現在日時 に更新し、終了する。
　・登録エラー：補償 Batch を開始する（(4)）。

### 6.4 Batch の連鎖と中断

　・チェック Batch・登録 Batch・補償 Batch は、登録対象ごとに 1 つの Batch とし、finish で次の Batch を開始する。処理単位（scope）の件数は【要確認 A-1・E-10】。
　・Batch は処理単位でエラーが発生しても次の処理単位を実行するため、登録 Batch では取込管理.ステータス（登録エラー）で以降の処理単位を止める（(3)①）。
　・例外として捕捉できないエラー（ガバナ制限超過等）は execute 内で処理できないため、finish で当該 Batch のジョブのエラー件数（AsyncApexJob.NumberOfErrors）を確認し、1 件以上の場合はエラーとして扱う（登録 Batch では補償 Batch を開始する）。エラーの内容は Batch のエラーイベント（BatchApexErrorEvent）で 取込管理.異常内容 に記録する。
　・Batch は登録ボタンを押したユーザで実行される（作成者・所有者は取込ユーザとなる）。
